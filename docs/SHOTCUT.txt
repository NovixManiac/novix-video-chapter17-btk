Editen in Shotcut (stap-voor-stap)

Nieuw project / projectinstellingen

Start Shotcut → File → New Project.

Kies Video Mode: Automatic (dan matcht Shotcut de eigenschappen van je eerste clip) óf 
kies handmatig 1920x1080 @ 30 fps als je in 1080p opneemt (Udemy vereist minimaal 720p). 
Udemy Business

Importeren

Sleep opname.mp4 naar de Playlist en van daar naar de Timeline (v1). Altijd eerst in de playlist zetten is handig als je meerdere takes hebt.

Proxy (optioneel bij trage VM):

Als het afspelen stottert: Settings → Proxy → Use Proxy en eventueel Make Proxy (Shotcut kan proxy-bestanden genereren) — dit versnelt het editen. (Zie Shotcut proxy workflow). 


Knippen / trimmen

Zet de playhead op de plek waar je wilt knippen → druk S (Split) om te splijten.

Voor alle tracks tegelijk: Shift+S. (handig als je meerdere audio/video lagen hebt).

Selecteer ongewenste stukjes en gebruik X (Ripple delete) om de lege ruimte automatisch te sluiten. 
(Rechtsklik → Ripple Delete kan ook). 


Exporteren (Udemy-vriendelijke instellingen)

Udemy: minimaal 720p, bij voorkeur 1080p; aanbevolen bestandstype MP4 (H.264 + AAC); individuele bestanden moeten < 4 GB. 
Udemy Business
Udemy Support

Aanbevolen Shotcut export-instellingen (1080p bron):

Export paneel → kies Stock → H.264 High Profile of MP4 preset. 
(Als die niet bestaat, kies mp4 container, codec libx264.)

In Advanced (als je wil finetunen):

Video: Codec = libx264, Profile = high, Preset = medium/fast (afhankelijk van CPU).

Resolution: 1920x1080 (of match source).

Frame rate: match source (30 fps of 25 fps), Udemy resamples, maar beter zelf consistent blijven. 

Bitrate: voor 1080p kies ~8–12 Mbps (8000–12000 kb/s) als target VBR; 
veel instructeurs gebruiken ~10 Mbps als goede middenweg. (community guideline). 

Audio: Codec = aac, Bitrate = 128k–192k, Channels = 2 (stereo). Udemy vraagt stereo audio. 

Export File → kies bestandsnaam → laat exporteren. Test daarna het bestand in VLC/MPV (controleren op sync, audio stereo, zichtbare compressie).

Bestanden groter dan 4 GB: splits de lecture in meerdere stukken (Udemy limiet).
