1. Stappenplan: nieuwe repo + code pushen

Dit kun je voor elk hoofdstuk herhalen:

A. Repo aanmaken op GitHub
===================================
Ga naar GitHub : Create New Repo : novix-video-chapterX (X = hoofdstuknummer)
Naam: novix-video-chapterX (X = hoofdstuknummer)
Public, geen README aanvinken

B. Nieuwe directory in je VM
===================================
cd ~/projects
cp -r riscv-os64 novix-video-chapter17-btk
NOTE : Verwijder de DOC dir !!!!
cd novix-video-chapter17-btk

C. Git initialiseren en koppelen
===================================
git init
git branch -M main
git remote add origin git@github.com:NovixManiac/novix-video-chapter17-btk.git

D. SSH key toevoegen (eenmalig per VM)
===================================
eval "$(ssh-agent -s)"
ssh-add ../key_video
ssh -T git@github.com

E. Commit & Push
===================================
git add .
git commit -m "Chapter 17 - Back to the Kernel"
ssh-add ../key_video
git push -u origin main


✅ 2. Repo koppelen aan Udemy video

- Ga naar je cursus → Curriculum
- Klik op de betreffende video (bijv. Booting the System)
- In het video-bewerk scherm kun je Resources toevoegen
- Kies External link
- Plak de link naar je GitHub repo
- Geef een duidelijke naam, bijv. Novix Chapter 9 Source Code


3. Foute bestanden verwijderen en opnieuw committen (eenvoudigste)

Als je de bestanden al hebt gepusht, maar je wilt ze nu uit de repo verwijderen 
(maar het mag nog wel in de git‐geschiedenis blijven staan):

# Verwijder het bestand lokaal
git rm path/to/wrong_file.md   b.v. : kernel\terpaser.c

# Commit de wijziging
git commit -m "Remove wrong file from chapter X"    X = chaper number

# Push naar remote
git push
